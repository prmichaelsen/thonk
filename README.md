# thonk

Source for **endlessthonk.com** — a single new "thonk" emoji per day,
generated by Replicate's `google/nano-banana` model, displayed as a
growing tile grid.

- `site/index.html` — single self-contained static page, render-all
  grid with native `loading="lazy"` on every `<img>`.
- `site/style.css` — responsive CSS grid (5/4/3/2/1 columns by
  viewport), square tiles, hover-date overlay.
- `site/images/` — built copy of `images/` (regenerated by `build.py`
  before each deploy).
- `images/` — durable record. Every day's JPEG is committed here.
- `manifest.yaml` — day index, prompt rotation, accumulated scenes.
- `build.py` — render `site/index.html` from `manifest.yaml`,
  unconditional `cp -f images/*.jpg site/images/`.

No build framework. No JS. Plain HTML + CSS.

## Owning track

[`thonk-worker`](https://github.com/prmichaelsen/reflection) in
reflection. Steady-state daily generation + deploy runs through
that track's wake.

## Deploy

```
python3 build.py
wrangler pages deploy site/ --project-name=thonk
```
